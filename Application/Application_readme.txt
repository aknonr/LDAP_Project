# Application Katmanı

## Amaç
Use-case’ler, servis arayüzleri ve iş politikaları bu katmanda yer alır. Domain’i orkestre eder.

## Mevcut Durum
Henüz uygulama servisleri ve use-case’ler eklenmedi (iskelet aşaması).

## Planlanan İçerik
- RBAC servisleri (`PKG-004`)
- Job oluşturma / izleme use-case’leri (`PKG-011`)
- Discovery / Update arayüzleri (`PKG-007`, `PKG-008`)
- Messaging contract’ları (`PKG-009`)
